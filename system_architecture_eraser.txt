// ==================== CONNECTIONS ====================

React Native App (Expo) > FastAPI Backend: REST API / HTTPS + JWT

API Handler > Price Alert Service: Alert Notifications
API Handler > Entity Resolution Service: Product Matching
API Handler > Price Forecasting Service: Price Trends

Data Acquisition Layer > FastAPI Backend: Scraped Product Data

Price Alert Service > Relational Store: User Data and Wishlists
Price Forecasting Service > Relational Store: Historical Price Data
Entity Resolution Service > Relational Store: Normalized Products
Entity Resolution Service > Document Store: Raw Records

Data Extraction Engine > Document Store: Raw Scraped Records
